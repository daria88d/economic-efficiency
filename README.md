# СЕРВИС ДЛЯ РАСЧЕТА ЭКОНОМИЧЕСКОЙ ЭФФЕКТИВНОСТИ ОТ ВНЕДРЕНИЯ ТРЕНАЖЕРОВ ТЭС
Сервис для расчета экономической эффективности от внедрения тренажеров ТЭС позволяет на основании параметров энергоблока определить статьи экономии, дисконтированные потоки, срок окупаемости. Рассчитанные показатели представляются в числовом, графическом и табличном виде.
